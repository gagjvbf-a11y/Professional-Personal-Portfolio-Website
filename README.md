# Devarayapalli Ajay — Portfolio

A responsive, colorful personal portfolio for Devarayapalli Ajay, UI/UX Designer and CSE AI student at Joy University.

## Built with
- HTML5
- CSS3
- Vanilla JavaScript
- Lucide icons (CDN)
- Google Fonts (DM Sans + Space Grotesk)

## Run locally
Open `index.html` in your browser, or serve this folder with any static web server.

## Customize
- Update personal details and social links in `index.html`.
- Replace the concept project cards with real case studies and screenshots.
- Add your resume file and update the Download Resume action when ready.
- Add a profile photo if desired.
- The contact form opens the visitor's email application; it does not submit to a backend.
